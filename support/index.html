MoveRally support

Keep your rally
moving.

Help with accounts, Apple Health, activity syncing, private groups, challenges and notifications.

Account access

  1. Use the same email address originally used to create your account.
  2. If email confirmation is required, open the newest confirmation message before signing in.
  3. For password issues, use the reset-password option on the login screen.

Apple Health

  1. Open MoveRally → Profile and enable the Apple Health connection.
  2. Allow read access to steps, workouts and active energy.
  3. To change access later, use the Apple Health app’s Apps and Services settings.

Activity not updating

  1. Confirm Apple Health contains activity for the relevant date.
  2. Open Profile → Fitness connection → Sync last 7 days.
  3. Keep MoveRally open until the sync status completes.

Groups and challenges

  1. Open Friends to create a group or join using an invitation code.
  2. Group owners can share the current code from the group details page.
  3. Challenge creators can edit a challenge until its scheduled start time.

Notifications

  1. Open Profile → Notifications and enable device permission.
  2. Choose which invitations, updates, summaries and achievements you want.
  3. If permission was denied, enable MoveRally in the iPhone Settings app.

Delete your account

  1. Transfer or delete any private groups you own.
  2. Open Profile → Delete account & activity data.
  3. Confirm deletion. This removes your MoveRally profile and stored activity.
